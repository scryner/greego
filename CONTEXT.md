# Greego Project Context

## Goal
**React Flow-based AI Mindmap Chatbot 'Greego'.**

## Future Plan
This app will be packaged with **Tauri v2 (Rust)** in the future.

## Data Principle
Isolate logic into **Pure Functions** as much as possible.
*Rationale: To facilitate future porting of core logic to Rust.*

## API Communication
Isolate backend communication logic in a separate `services/api` layer.
